## 本地运行

需要 Node.js 与 pnpm。安装锁定依赖后启动桌面端开发预览：

```bash
pnpm install --frozen-lockfile
pnpm dev
```

执行生产构建：

```bash
pnpm build
```

此版本不是服务部署包，也不包含账号、模型密钥、用户数据、部署配置或项目历史状态。前端遵循 `package.json` 的 Node.js 版本范围；服务端另要求运行时支持 `node:sqlite`，本轮未验证服务端。
